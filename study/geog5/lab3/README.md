## 核心ルール（Lab 2 → Lab 3）

- isoline は交差しない / 間隔＝傾度 / 変化は直角方向
- **密な isotherm** → 急な気温勾配
- **密な isobar** → 急な気圧傾度 → 強風候補
- 気温図 → control を一文（緯度 / 陸水・continentality / 標高・lapse rate / 海流 / 雲・albedo）
- 気圧図 → **高→低**、そのあと **Coriolis**（NH 右 / SH 左）
